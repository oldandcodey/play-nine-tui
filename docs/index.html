Play Nine Scorekeeper

A fairway-green terminal scorekeeper for the card game Play Nine — not a card engine. Enter hole scores, track running totals (lowest wins), resume unfinished rounds, and finish with ASCII champagne & fireworks.

MIT MSRV 1.85 SSH-friendly JSON history

Features

  • 9- or 18-hole rounds · up to 8 players
  • Running totals with ▲ leader markers (lowest wins)
  • Jump/edit prior hole+player scores with e
  • Resume unfinished rounds · JSON history summaries
  • Funny golf sayings + fairway accent under the banner
  • Champagne toast, fireworks, and confetti celebration (SSH-safe ASCII)

Build & run

git clone https://github.com/oldandcodey/play-nine-tui.git
cd play-nine-tui
cargo build --release
./play
# or: cargo run

Working directory matters: scores are written to data/play_nine.json relative to CWD. Run from the project root.
